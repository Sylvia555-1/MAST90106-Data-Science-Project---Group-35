# 人造 LAOS：用于变化起点检测的 DWT 特征初筛

## 目标与本轮范围

目标是找到周期加载保持不变后，额外应力变化开始的时间。按用户确认，首轮只用 control 与 clot_A 筛选特征。clot_B/C 完成文件质量检查，但尚未参与特征比较。四条记录均来自同一生成方式，不能当作四位独立供者。

本轮先完成数据核对、特征提取、无噪声/噪声影响对照与起始位置敏感性检查。随后按用户选择，完成R6与普通RMS的简单起点规则比较，结果见下文。特征图中300秒竖线来自已知生成设定，不是检测结果。真值和元数据已经用于探索性核对，本轮不属于盲测。

## 数据能否使用

可以用于当前的合成信号特征研究。四条记录均有180,000个原始点，覆盖[0,1800)秒，100 Hz均匀采样；没有缺失值或重复时间。每个1 Hz加载周期有100个点。四条记录的应变和剪切率输入完全相同，与给定正弦加载公式一致。

检查脚本最初错误地预期包含1800秒末端点。核对CSV后确认文件采用半开区间，已修正代码；没有补点或修改源数据。

真值列与说明文件公式一致，最大绝对差约5.7×10⁻¹⁴。按公式重建干净应力后，噪声残差除以设定标准差，其标准差约0.997–1.005，滞后一阶相关约0.798–0.801，与说明中的AR(1)设定相符。DWT分解后可重建原信号，四条记录的最大误差低于2.4×10⁻¹⁴ Pa。这些检查验证文件和计算一致性，不证明生理真实性。

## 为什么不能照搬 step 的特征

step 中的应力可以整体向上增长，所以慢趋势均值及其变化率有用。这里的LAOS应力持续正负摆动，增长主要体现在摆动幅度和波形改变。正负值相互抵消后，均值不能可靠代表振荡有多强。

例如clot_A的普通应力RMS，在早期与后期完整10秒窗口中的中位数分别约0.00439 Pa和9.84 Pa。相比之下，均值接近零且受窗口内增长、相位和噪声影响。因此首轮优先比较各尺度的强度，而不将A8均值作为主特征。

## 简单实验方法

1. 保留全部原始时间和幅值；不插值、不重采样、不做幅值归一化。
2. 对整段应力做db2、8层DWT，使用symmetric边界延拓。逐层重建D1–D8和A8回到原始时间网格。
3. 使用10秒统计窗口，每1秒移动一次。每窗覆盖10个完整加载周期；各窗口重叠，不能作为独立样本。
4. 对每层计算Rj，即该层重建细节的均方根强度；额外计算R6变化率、P6、H13和R45/R6。
5. 同时保留原始应力RMS作为简单参照。R45=sqrt(R4²+R5²)，H13=sqrt(R1²+R2²+R3²)，P6=R6²/sum(R1²…R8²)。P6只是所选细节层中的占比，不是总物理能量占比。
6. 使用真值公式重建无噪声信号，另提取残差噪声特征，单独保存。RMS与占比是非线性统计量，不能简单把干净特征和噪声特征相加。
7. 去掉记录开头的一个完整周期后重新计算，比较相同绝对时间窗口，检查DWT对起始位置的敏感性。保守排除两端16秒；本轮讨论的起点附近远离边界。

图中的时间是窗口中点。当前是全记录离线DWT，窗口和滤波都会使用该中点之后的数据；较早出现的响应不能解释为提前预测。1秒移动间隔不代表1秒定位精度。

## 结果及其含义

| 特征 | 本轮发现 | 对起点检测的价值 |
|---|---|---|
| R6：D6响应强度 | 增长后明显上升，观测值接近干净信号结果 | 优先保留，但需要与自身背景起伏比较 |
| R6变化率 | 能响应增长，但有明显交替起伏；后期近平台也会大幅正负变化 | 不能直接把每一个峰或正值当成增长起点 |
| R1–R8 | 多层都随增长增强；R6是当前设置下主要细节强度之一 | “会变大”本身不足以证明定位更好；首轮不把八层都加入检测规则 |
| P6：D6占比 | 起点附近与对照组大量重叠，并存在规律波动 | 暂不作为起点主特征 |
| R45/R6：尺度之间的相对强度 | 起点附近与对照组大量重叠；后期有变化 | 暂作辅助，不能直接称为谐波比或材料非线性指标 |
| H13：较快尺度合并强度 | 会随增长增加，而且干净信号也有明显H13 | 不能当作纯噪声指标；可以另作响应候选，但尚未证明提供独立帮助 |
| A8均值 | 不直接代表正负摆动的幅度 | 首轮不优先使用 |
| 原始应力RMS | 已能清楚表现振荡幅度增长，曲线比R6更平稳 | 必须保留为参照，目前没有证据证明DWT比它更准确 |

在clot_A增长后最初30秒内，完整落在该区间的10秒窗口中，R6中位数从基线约0.00361 Pa升至约0.0319 Pa，普通RMS从约0.00439 Pa升至约0.0401 Pa。这只是描述性区间比较，不是检测门槛。

同一区间的H13中位数：观测约0.001129 Pa，干净信号约0.001129 Pa，噪声残差约0.000116 Pa。无噪声响应已经可以产生明显H13，因此“快尺度增强=噪声增加”的解释在这里不成立。

## 必须保留的限制

- **恒定信号也有特征起伏。** 无噪声control在20–200秒区间的R6峰峰值约为均值的4.78%。去掉一个完整加载周期后，对相同窗口算出的R6也会改变。这支持DWT计算起点及窗口对齐会影响特征，不能把所有起伏当成材料变化。
- **变化是逐渐开始的。** 生成函数在起点处连续且初始斜率为零。clot_A设定起点为300秒，第一个严格正的状态采样点为300.01秒；前者才是生成设定的起点。检测有噪声信号时，不应期待一个尖峰精确标出300秒。
- **多种因素同时改变。** 材料响应参数、波形与噪声强度共同变化；单个特征增加不能说明是哪一因素导致。clot_A的设定噪声标准差也随响应增长明显增大。
- **只做了一对记录的探索。** 没有多随机种子或独立生成机制；当前不能证明检测泛化能力，也不能解释为真实凝血诊断。

## 已完成的下一小步：起点规则比较

按用户确认，只比较R6与原始应力RMS。对照记录中完整落在20–200秒内的窗口用于校准；200–1780秒内的窗口用于检查候选变化。各特征的主门槛为“背景中位数 + 6 × 1.4826 × 背景MAD”，MAD为相对中位数的绝对偏差的中位数。两者使用相同形式、但数值不同的门槛。这是工作规则，不是已校准的误报概率。

连续三个窗口超过门槛才保留候选段；窗口长10秒、移动1秒，所以三个窗口合计覆盖12秒，并非三个独立重复。把第一个超限窗口中点作为一个约定的起点估计，同时保留整个窗口区间及第三个窗口结束时间。

| 主规则结果 | R6 | 原始应力RMS |
|---|---:|---:|
| 门槛（Pa，近似值） | 0.004023 | 0.004435 |
| 首个超限窗口 | 297–307秒 | 293–303秒 |
| 中点估计 | 302秒 | 298秒 |
| 与设定300秒的有符号差 | +2秒 | −2秒 |
| 第三个窗口结束 | 309秒 | 305秒 |
| 该control监测区间内候选段数 | 0 | 0 |

**两者都找到了增长；在这一规则和时间标记下，绝对差同为2秒，没有证据证明DWT更准确。** RMS的298秒不能解释为提前预测，因为对应窗口到303秒才结束。DWT还额外使用窗口外及未来的滤波数据，所以第三个窗口结束时间也不等于真实在线报警时间。

敏感性检查：

- 门槛倍数改为3、6、9时，原始记录R6的估计分别为301、302、302秒；RMS为298、298、299秒。没有根据这些结果重新挑选最有利的门槛。
- 较宽松的3倍门槛下，RMS在control出现2个候选误报段；6倍和9倍为0。R6在这条control的三个门槛下均为0。不能把一条记录上的0次误报写成总体0%误报率。
- 去掉开头一个完整周期、保留同一绝对时间窗口和原门槛后，主规则R6估计从302移至301秒，RMS仍为298秒。R6具有对齐敏感性；更接近真值的那一次不能据此选作“最佳结果”。

下一步可将固定规则原样应用到B/C，作为同一生成方式下的追加场景核对。由于元数据和真值已经看过，不能称盲测。若要估计可靠的误报率和定位精度，需要额外生成多个随机种子的无变化及变化记录，并冻结独立测试数据。

## 文件与运行

- `audit_data.py`：质量和生成公式核对，英文注释。
- `explore_features.py`：观测特征、真值对照、图像和敏感性检查，英文注释。
- `compare_onsets.py`：R6与普通RMS的相同形式规则、门槛敏感性和候选时间比较。
- `Audit_and_Features.ipynb`：可逐步调用上述脚本的入口。
- `01_data_audit/`：数据质量、普通窗口统计、来源哈希。
- `02_plan/`：下一阶段简明方案。
- `03_observed_features/`：只由观测应力计算的特征。
- `04_truth_review/`：干净信号、残差噪声和描述性区间结果。
- `05_figures/`：结果图。
- `06_validation/`：重建与对齐检查。
- `07_onset_comparison/`：门槛、候选区间、中点时间误差与规则说明。

本机运行：

```bash
/opt/anaconda3/bin/python audit_data.py
/opt/anaconda3/bin/python explore_features.py
/opt/anaconda3/bin/python compare_onsets.py
```

从本目录运行，依赖numpy、pandas、PyWavelets、matplotlib。所有原始文件保持不变。
