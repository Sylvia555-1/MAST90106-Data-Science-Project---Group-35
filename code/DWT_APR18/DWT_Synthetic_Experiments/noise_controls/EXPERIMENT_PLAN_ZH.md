# 人造流变信号的 DWT 特征与噪声影响研究：首轮实验方案

版本：v1，2026-09-26。本文保留实验执行前的方案措辞。**当前阶段 1–5 已运行完成**，结果及实际文件结构见 [最终报告](results/06_summary/FINAL_REPORT_ZH.md) 与 [README](README.md)。下文的“拟使用”“尚未运行”等表述均属于原方案，不代表当前执行状态。

用户已确认：首轮只判断特征变化与设定材料响应、噪声的关系；不去噪、不修改原始应力。

## 1. 研究目标与验收边界

核心问题：**在固定周期加载下，DWT 提取的哪些特征能描述材料响应的演化？这些特征的变化有多少受到噪声影响？**

首轮将分别回答：

1. 观测应力在哪些时间区间、哪些尺度上表现出响应增强？
2. 增强主要呈现持续增长，还是短暂波动？
3. 同一特征在干净信号与含噪信号中有什么差别？
4. 哪些结论对窗口长度和分析起点稳定，哪些不能可靠解释？

每个窗口都同时包含周期响应与噪声，control 也不是纯噪声。首轮采用连续的影响指标，不强行把窗口分成“材料”或“噪声”两类。

当前可验证的是**已知生成机制下的特征归因**。这不等于仅凭未知观测信号就能自动分离材料变化和噪声。后者需要额外对照、独立轨迹和单独评价。当前数据已被查看，本轮属于探索性开发研究，不是盲测。

## 4. 将可观测分析和真值评价分开

### 4.1 可观测分析

分析程序只接收 CSV 中的时间、应变、剪切率和应力，以及固定的 DWT 设置；不读取起点标签、种子或潜在模量。

生成特征表与图后保存配置和文件哈希。参考段统一设为 20–200 s，基于我们已知的模拟设计选取，属于开发设定；不声称是算法自动找出的无变化段。

### 4.2 事后核验

单独的评价程序读取参数和生成公式，恢复：

- s(t)：设定的干净应力；
- n_gen(t)：由原种子产生的随机噪声；
- y(t)：CSV 中的观测应力。

首先核对 y≈s+n_gen，按原 CSV 的九位有效数字保存格式检查复现。为使后续代数核验精确，定义 n_eff=y−s；它包括设定噪声与极小的保存舍入误差，报告两者差值。

随后对 s、n_eff 使用与 y 完全相同的小波、边界和窗口设置。真值只用于解释和评价；不能据此反复改参数，再宣称获得独立成功。

不执行原生成脚本的主程序，因为它会写文件，且包内缺少其引用的 `source/APR18.xlsx`。核验读取已保存的基线参数和种子；此前已从本机 APR18 工作簿独立核对基线。

## 5. 固定的首轮计算设置

| 设置 | 首轮值 | 理由 |
|---|---|---|
| 方式 | 离线，全记录先分解 | 减少逐窗口反复延拓；可使用未来信息，因此不报告实时性能 |
| 小波 | db2 | 与此前可行性检查一致；不声称最优 |
| 层数 | 8 | 同时覆盖载波附近与较快尺度 |
| 边界 | symmetric | 与此前一致，另做边界标记 |
| 输出 | A8 与 D1–D8 重构到原始时间网格 | 用真实时间展示；检查各分量之和 |
| 主窗口 | 10 s、不重叠，即 1000 点 | 每窗含 10 个加载周期；作为描述性起点 |
| 边界标记 | 首尾各 20 s | 本配置下的保守范围；展示但不纳入主要结论，执行时核验滤波支持范围 |
| 参考段 | 20–200 s | 避开起始边界，位于所有已知设定起点之前 |

分解在整条记录上进行，窗口只是汇总；相邻窗口的特征不因此独立。图中显示窗口区间，中心点仅用于绘图，不能当作精确事件时间。

| 层 | 名义频带 / Hz | 用途 |
|---|---:|---|
| D1–D3 | 6.25–50，分三层 | 检查较快活动，不预称为噪声 |
| D4 | 3.125–6.25 | 诊断留存 |
| D5 | 1.5625–3.125 | 载波相邻尺度 |
| D6 | 0.78125–1.5625 | 包含 1 Hz 载波，主特征起点 |
| D7 | 0.390625–0.78125 | 载波相邻尺度 |
| D8 | 0.1953125–0.390625 | 诊断留存 |

这些不是理想频带分割；1 Hz 周期响应会在多个尺度留下细节。不能照搬 EEG 的频段含义，也不能用某层编号直接表示材料机制。

## 6. 先提取四个主特征

设 d_j 为第 j 层重构细节，窗口内 E_j=mean(d_j²)，R_j=sqrt(E_j)。保存所有层的 R_j 作为审计表，但主要解释以下四项，暂不加入熵、PCA 或 ML。

| 特征 | 定义 | 解释与注意事项 |
|---|---|---|
| R6 | 第 6 层 RMS，Pa | 周期附近的响应强度；不是 G′ 的直接估计 |
| H13 | sqrt(E1+E2+E3)，Pa | 较快尺度综合活动指数；不是重构后相加信号的 RMS，也不是噪声估计 |
| P6 | E6 / sum(E1…E8) | 所选细节层之间的相对活动分布；不是全信号能量占比，不含 A8，局部交叉项未进入该定义 |
| V6 | 相邻窗口 R6 差 / 窗口中心间隔，Pa/s | 观察增长速度和波动；第一窗无定义 |

分母为零时将占比标记为不可计算。主结果报告绝对值；相对误差在参考分母接近零时不报告百分比。

RMS 和能量相互确定，不作为两种独立信息。P6 可能对纯幅值缩放不敏感，需与 R6 同时解释。D5、D7 的 RMS 用于核对结论是否依赖单一层。

## 7. 怎样判断噪声的影响？

### 7.1 先区分“分量强弱”和“变化来源”

一个尺度中，噪声能量较小，并不意味着某个细微起伏没有受到噪声影响；反之，背景噪声较强，也不意味着后续增长来自噪声。这两件事分别计算。

**分量强弱。** 对每层、每个窗口计算：

E_s=mean[d_j(s)²]；E_n=mean[d_j(n_eff)²]；C=2mean[d_j(s)d_j(n_eff)]。

验证 E_y=E_s+E_n+C。交叉项 C 可能正也可能负，不能省略。绘制 10log10(E_s/E_n) 的局部信噪比；零能量时标记无穷或不可计算，不用任意小数伪装为实测值。

该信噪比是已知生成器下的事后诊断，不是从未知观测直接估计得到的信噪比。0 dB 只表示两个单独分量能量相等，不是材料/噪声事件判定阈值。

**对特征变化的影响。** 对每个特征 F 定义：

B_F(k)=F_y(k)−F_s(k)。

B_F 表示在相同干净响应上加入该次噪声后，特征被改变了多少。它不等于 F_n，因为 RMS、占比等不是线性运算。

以参考段的各特征均值为基准，计算：

ΔF_y(k)=ΔF_s(k)+ΔB_F(k)。

三者都是有正负号的差值。这使我们能够分别展示“干净响应本身的变化”与“噪声引入偏差的变化”，而不把总能量占比误当成变化来源占比。不强行转换为加起来为 100% 的贡献百分比。

### 7.2 允许的结果表述

- 若干净特征与含噪特征都持续增长，可说“在本生成器下，该增长在不含噪声时也存在”。
- 若某个短暂波动主要出现在 B_F 中，可说“该次实现中的这一波动受到噪声明显影响”，并展示数值。
- 若两者同时变化，或对窗口/平移敏感，报告混合影响或不确定，不强行分类。
- 每项结论附时间区间、层级、绝对变化量、噪声影响量及稳定性结果。

这里的“判断”依赖模拟真值核验；无法把它写成面对真实未知数据时已成功自动识别噪声。

## 8. 按阶段实施，每一步都验证

### 阶段 1：只做 control + clot_A 的数据和 DWT 核验

检查时间间隔、列名、有限值、点数、单位、输入一致性；保存源文件哈希。完成分解、逐层重构与总重构检查。对于本批量级数据，最大绝对应力重构误差要求 <1e−10 Pa，同时报告相对误差；失败就排查代码，暂不解释结果。

输出：数据检查表、原始应力总览与局部周期图、分层细节图。图中不把连续的 1 Hz 振荡称作新事件。

### 阶段 2：计算可观测特征

固定配置计算四个主特征和各层 RMS，画全程及参考段。对比原始应力 RMS、相同 10 s 窗口的正弦拟合 G′/G″与拟合残差 RMS。

正弦拟合只是独立参照，残差也可能包含窗口内模量变化造成的拟合不足，不能直接当噪声真值。首轮不设置自动报警阈值，不借用原脚本的 30 s 报警延迟作为 DWT 成绩。

### 阶段 3：事后重建分量，解释变化

重建 s、n_gen，验证 CSV 序列化精度；计算 n_eff。验证各层线性关系 d_j(y)=d_j(s)+d_j(n_eff)，以及窗口能量含交叉项的恒等式。线性关系采用 1e−10 Pa 绝对误差核验；能量恒等式使用绝对与相对误差结合，并记录容差与最大误差。

输出信噪比热图、含噪/干净特征叠加、B_F 与 ΔF 分解表。图中这时才叠加生成器起点，明确是已知标签，并非算法找到的起点。

**关键确认点 A：** 向用户解释哪些增强由干净响应支持、哪些波动受噪声影响、哪些仍混合；在此基础上确认是否需要追求自动判别或后续去噪。首轮结论可以是“目前特征无法可靠区分”，不以成功分离作为强制结果。

### 阶段 4：检查稳定性

- 窗口：固定小波，分别使用 5、10、20 s；按共同物理区间比较阶段性结论，避免把不同窗口的中心当成完全同一时刻。
- 分解起点：分别裁去开头 1、8、32 个样本再分解，保留原绝对时间；不循环回卷、不补接尾部数据。重新汇总到完全相同的物理时间窗口，在共同内部区间比较。
- 边界：验证首尾 20 s 标记对当前滤波器支持范围足够；若不足，扩大排除区并记录理由，不把边界伪影称为材料事件。

报告各变体的最小/最大特征值、与主配置的绝对差及解释是否改变。这是有限敏感性检查，不等于遍历所有平移，也不据此寻找最漂亮的配置。首轮不做大规模小波族搜索。

### 阶段 5：固定方案应用到 B、C

不根据 B、C 的真值换特征或窗口，用同一流程逐条报告。四条均已被查看，因此这是同类场景复核，不报告独立测试准确率或置信区间。

**关键确认点 B：** 提交结果后，由用户决定下一步是增加噪声干扰对照、研究候选起点判据，还是开展去噪。三者不混成首轮任务。

## 10. 期待获得什么，不预设什么？

期待得到的是一份经过核验的映射：**时间区间 → DWT 特征变化 → 在设定生成机制下的来源与不确定性**。

根据先前可行性检查，D6 可能跟随主要响应增长，而较快尺度也可能包含干净载波的贡献；这是已有线索，不是本轮尚未运行实验的新结果。不会预设高频等于噪声、DWT 优于 RMS，或能定位到 0.01 s。

如果 DWT 与简单 RMS 表现相近，就报告额外价值尚未体现；如果某些特征对平移明显敏感，就限制其定位用途；如果噪声和响应在特征上混合，就承认仅靠当前数据无法自动区分。

本轮不提供凝血特异性、真实血液微结构识别、ML 泛化、去噪质量或实时报警性能结论。
