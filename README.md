# MAST90106 Data Science Project – Group 35

This repository contains the code, documentation, and analytical workflows developed for the MAST90106 Data Science Capstone Project in collaboration with Haemograph.

## Project Overview

This project investigates changes in blood rheological behaviour using conventional rheological analysis, physics-based modelling, and signal-processing techniques.

The implemented methods include:

- **Conventional Rheological Analysis:** Analysis of rheological properties and indicators.
- **FFT and STFT:** Frequency-domain and time-frequency analysis.
- **CWT:** Continuous Wavelet Transform analysis.
- **DWT:** Discrete Wavelet Transform analysis.
- **t-ESSTV:** Physics-based modelling of blood rheological behaviour.

## Code and Documentation

The code and supporting materials for each analytical method are organised into separate folders or ZIP archives.

Each method includes its own README file containing relevant implementation details, dependencies, and instructions for running the code.

For ZIP archives, please extract the files and refer to the included README before execution.
