# AI Usage Declaration

## Generative AI Tools Used

Generative AI tools, including ChatGPT, were used to support the development and documentation of this Capstone Industry Project.

## Purpose of AI Use

AI tools were used for the following purposes:

- **Research support:** Assisting with the understanding of technical concepts and relevant methodologies.
- **Programming assistance:** Supporting code debugging, error identification, and implementation improvements.
- **Data analysis support:** Assisting with the interpretation and discussion of analytical approaches and results.
- **Writing assistance:** Improving grammar, clarity, organisation, and readability of project documentation and reports.
- **Brainstorming:** Supporting discussions about potential approaches, project limitations, and presentation structure.

## Human Responsibility and Verification

All AI-generated suggestions were reviewed and evaluated by team members before being incorporated into the project. Team members remained responsible for the implementation, validation, interpretation, and presentation of the final work.

AI tools were used as supporting resources rather than substitutes for independent research, critical analysis, or decision-making.
